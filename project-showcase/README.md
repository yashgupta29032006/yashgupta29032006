## 🏗️ Core Engineering Themes

1. **Multi-Agent Orchestration & Closed-Loop Autonomy:** Moving past single-prompt LLM wrappers to hub-and-spoke agent architectures with deterministic state machines and sandboxed execution boundaries.
2. **Intelligent Video Analytics & Edge Vision:** Designing high-throughput, low-latency computer vision pipelines that preserve user privacy by processing features locally on edge hardware.
